# 🦖 DinoRun — Cinematic Edition

A modern reimagining of the classic Chrome Dino game, built entirely with **HTML5 Canvas, CSS, and Vanilla JavaScript** in a **single HTML file**.

Designed as an experiment to explore how far a browser game can be pushed using modern web technologies while keeping the project lightweight and dependency-free.
